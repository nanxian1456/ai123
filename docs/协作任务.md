# 协作任务表

Codex 与 Claude Code 共用的任务表，规则见根目录 [AGENTS.md](../AGENTS.md) 的“分工流程”。两个助手不能直接对话，所有分工、复查和留言都写在本文件里，**每次开始工作前先读一遍本文件，尤其是第六节留言板**。

- **负责人**：`Codex`、`Claude`；`待领取` 表示任何一方都可以领取；`用户` 表示需要人工完成。
- **状态**：待领取 → 进行中 → 待复查 →（需修改时回到进行中）→ 待验收 → 完成；另有“等待”（等对方先完成某项）和“暂缓”（需要用户决定或外部条件）。
- **复查人**：负责人之外的另一方。
- **涉及文件**：领取时写清楚，修改范围变化时及时更新；不得与对方“进行中”任务的涉及文件重叠。
- **备注**：开始时间、修改了对方测试的原因、未验证项等。

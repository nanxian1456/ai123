 # AI人脉地图初版

这是一个可运行的微信小程序和 Java 后端初版，用于验证联系人录入、搜索、地区分布和人物关系管理的主业务闭环。

产品范围不包含站内聊天、私信、消息或会话功能。微信仅用于登录及用户主动分享加密备份文件；文本整理只处理用户粘贴的人物介绍或联系人资料。

## 目录

- `backend`：Java 21、Spring Boot 4.1 REST API。
- `miniprogram`：原生微信小程序 TypeScript 工程。
- `outputs`：需求分析文档。

## 已实现

- 看板统计：联系人、城市、单位数量和最近联系人。
- 联系人：新增、详情、搜索、城市筛选、删除接口。
- 联系人维护：编辑资料、标签筛选、删除联系人及关联关系。
- 人脉地图：可旋转缩放的离线边界地球，使用黑色背景、卫星地表纹理、静态云层、昼夜光照和蓝色大气光晕和高亮国界；按国家、省份和城市逐级查看人数。进入城市后，点击联系人卡片或地图标记可定位并放大到该联系人，点击“设置位置”可编辑位置；尚无经纬度时仅使用城市中心附近的默认点，不代表精确地址。联系人详情可从联系人页进入。
- 地区统一与搜索：联系人保存的地区保持原样，统计、筛选和搜索按统一名称比较，如“江苏省 / 江苏 / Jiangsu”、“南京市 / 南京”、“China / 中华人民共和国 / 中国”视为同一地区。国家为空但省份或城市能识别为中国大陆地区时按“中国”归类，只有城市时补全省份；港澳台及无法识别的地名不自动补国家。名称表在 `miniprogram/utils/regions.ts`。地图搜索在任何层级都会同时列出其他层级的匹配地区（如“中国 › 江苏 › 南京”）和全部匹配联系人，点击地区跳到该层级，点击联系人跳到其城市并只显示该联系人；地区不完整的联系人直接打开详情。
- 人物关系：在联系人详情中新增、查看和删除关系列表。
- 图谱：标签树与关系网、分类管理、搜索定位、筛选、关联排行、最短路径和 N 度隔离。
- 本地数据：个人资料、头像、联系人、标签和关系保存在微信小程序的本机存储中，按微信账号隔离。
  大数据按 200KiB 分片，全部新分片写入成功后才提交索引；旧单键数据及早期开发版的联系人、关系数组分片均可读取，并在下次成功保存时迁移。仍受微信总存储容量约束，原子替换需要暂存新旧两代数据，空间不足时保留旧数据并提示导出备份。
- 八位导入码：每个微信账号有固定的 `3位数字+2位字母+3位数字` 导入码；用户公开昵称后，其他用户可按码获取其主动公开的最小资料并保存为本机联系人。未发布的旧服务器资料不可导入。
- AI 信息预填：通过 DeepSeek 的兼容接口提取联系人结构化信息。
- 后端基础能力：统一参数校验和异常响应、请求追踪日志、缓存、分页及 API 限流。

## 页面与录入方式

首页优先提供「新增联系人」与「智能整理」，下方查看本机统计、最近联系人以及联系人库、图谱和地图入口。联系人页的标签横向滚动，搜索、地区与标签筛选可统一清除。关键词输入后暂停约 250ms 自动筛选，无需按回车；点搜索或回车立即执行，清空关键词立即恢复当前标签／地区下的列表。连续输入、离页和账号切换会让旧查询失效，新增标签弹窗也绑定发起账号，切换后不能继续创建。

新增联系人支持「手动填写／AI 整理／导入码／批量录入」切换；切换不会清空已经填写的草稿。首页智能整理直接进入 AI 模式；保存入口固定在表单底部，AI 整理和导入期间暂不能提交。编辑已有联系人保留手动和 AI 整理入口。

联系人详情默认收起未填写字段，可展开查看；电话和邮箱的复制按钮只复制选中字段。我的页提供备份恢复、个人资料、导入码和设置入口；设置只在“我的”页以独立功能卡展示，其他业务页不再放顶部设置按钮。我的页优先显示联系人／关系数量和备份状态，缓存容量与头像大小通过“查看存储详情”展开，读取错误显示在页面上方并可重试。联系人列表分批渲染，关键词覆盖电话、邮箱、备注、地址等本机字段；地图列表精简展示数据，提供当前地区及全库搜索。

所在地的国家／地区使用内置列表，可按中文名、英文名、代码或常用简称搜索，显示当前账号最近使用的选项，不读取 IP 或自动定位。选择中国后可联动选择省市，也可切换为手动填写；海外省／州可留空。确认更换国家时会清空原省市、详细位置和坐标；更换省、市时同样提醒清理下级位置，取消不会修改草稿。国家和省市均允许暂不设置。

旧国家名称和手填地区保留原值；统计、筛选及地图搜索使用统一名称，无法识别的旧国家会在编辑时提示确认。当前联系人仍保存名称字符串，代码只用于选择和最近使用记录，以兼容已有备份。选择、保存与统计均在本机完成；海外城市不填省／州时，坐标接口仍可按国家和城市定位，需同步更新并重启后端。真实坐标仍依赖定位服务，国家列表不会自动生成联系人坐标。

## 图谱使用说明

构建后在微信开发者工具重新编译，从底部“图谱”进入，顶部切换“标签树”和“关系网”。已有账号可离线读取本机图谱；首次登录和旧数据迁移仍需要后端。

图谱加载及恢复：同账号已有图谱时，返回页面只在后台检查变化，保持可交互且不反复显示遮罩；首次加载、账号切换清空后及失败重试仍显示加载保护。数据或画布尚未就绪时，触摸、排行、模式切换、搜索等操作会受到保护；加载失败显示明确的重新加载按钮，不把失败显示成空图谱。切换账号会清除旧画布、抽屉和搜索结果，旧账号打开的新增、重命名、删除、导入等操作不能继续写入新账号；迟到的读取和搜索结果也不会覆盖当前账号。画布初始化失败可单独重新初始化。性能降级、批量操作上限及尺寸变化后的触摸校准仍需后续处理和真机验证。

联系人页的「管理分类」可直接打开图谱分类管理。分类用于树形分组，联系人标签用于筛选，两者分别维护。编辑表单时请先保存，再前往管理分类，避免未保存内容丢失。

- **标签树**：以本人为中心展示分类。点击分类查看该分类及子分类中的联系人；双击分类聚焦分支，点击“显示全部”或中心节点退出聚焦。联系人在分类抽屉中列出，不作为标签树的画布节点。
- **分类管理**：右上角“+ 分类”新建顶层分类；分类抽屉可新建子分类、重命名和删除。“管理”中可添加、隐藏或恢复推荐分类，画布中的推荐节点也可双击添加。删除分类会同时移除子分类和相应归类，联系人及其关系保留。名称最多 20 字，最多 1000 个分类、16 层。
- **分类录入**：图谱页不再新增联系人，联系人统一在联系人页新增。分类抽屉点击“导入已有联系人”，可搜索、多选尚未显示在该分类（含子分类）中的联系人并一次归入；任一联系人已达 20 个分类时整批不导入。“未分类”为自动汇总，不提供导入。分类和联系人标签分别维护，已有标签不会自动变成树分类。已有联系人可在编辑页多选分类，再点一次取消归类，保存后同步到标签树。
- **关系网**：联系人、单位、城市分别生成节点；人物关系和单位、城市归属生成连线。点击节点或关系查看详情，点击联系人详情里的“添加关系”维护关系。拖动节点调整位置，拖动画布空白处平移，双指缩放。
- **搜索和筛选**：标签树可搜索联系人、分类，关系网可搜索联系人、单位和城市；点击结果定位，唯一结果可按键盘搜索键直接定位。“筛选”控制节点类型和关系类型的显示。
- **排行和工具**：“排行”按节点连线数展示前 10 名，包含联系人、单位和城市。打开“工具”可适配窗口、重置视图、暂停布局、隔离 1–3 度节点；开启“最短路径”后关闭抽屉，依次点击起点与终点。排行、隔离和最短路径按完整关系网计算，显示筛选不会重新计算它们；路径可能经过共同单位或城市。

分类树、联系人归类和隐藏推荐项沿用现有账号隔离、原子分片存储，并包含在加密备份中。不要用压缩包中的旧存储实现覆盖当前实现，也无需接入演示或清空数据模块。自动化验证范围及真机待测项见下方“测试”和[真机测试清单](docs/真机测试清单.md)。

## 启动后端

在 `backend` 目录运行：

```powershell
.\mvnw.cmd spring-boot:run -Dspring-boot.run.profiles=dev
```

也可以运行 `.\start.ps1 -Profile dev`，或用 `.\start.ps1 -Profile dev -Background` 在后台启动。后台启动日志写入 `backend/logs/`，脚本只表示进程已发起，需检查日志或访问 `http://127.0.0.1:8080/actuator/health` 确认就绪。

服务启动后访问地址为 `http://127.0.0.1:8080`。后端用于微信登录、首次导出旧数据、AI 提取和导入码公开资料交换；既有 H2 数据不会自动删除。

后端配置分为公共、开发和生产三个文件。直接运行应用必须显式选择 `dev` 或 `prod`，遗漏或混用环境会拒绝启动；Maven 开发启动器沿用本机 `dev` 默认值。开发环境优先读取外部文件 `backend/config/application-local.properties`（在仓库根目录或 `backend` 目录启动均可），并兼容现有 `backend/application-local.properties` 和 `backend/src/main/resources/application-local.properties`；这些文件均不得提交，Maven 明确排除源码资源目录中的本机密钥文件。推荐通过环境变量配置密钥。生产环境不导入本机密钥，要求 PostgreSQL、必要凭证和 HTTPS 公开地址。

生产数据库使用 Flyway 版本化迁移，Hibernate 仅校验结构。空库自动执行 `db/migration/V1__initial_schema.sql`；已有库不会自动标记基线或修改已有表，需备份并核对结构后显式确认基线。H2 到 PostgreSQL 的真实数据迁移需在副本演练后执行，此次代码修复没有操作本机或生产数据。构建后运行 `python scripts/verify-backend-artifact.py`，检查 jar 未包含本机密钥文件或明文密钥属性。

AI 默认每账号每天 20 次、单服务进程每天 200 次，可通过 `AI_ACCOUNT_DAILY_LIMIT` 和 `AI_GLOBAL_DAILY_LIMIT` 调整。当前计数在内存中，重启会重置，多副本部署须先改用共享持久化配额。开发环境默认忽略转发请求头；生产环境沿用 Tomcat 的 `native` 策略，只应在代理移除客户端伪造头、后端仅接收可信代理流量时使用，并按实际地址限制 `SERVER_TOMCAT_REMOTEIP_INTERNAL_PROXIES`。直接暴露后端时设置 `FORWARD_HEADERS_STRATEGY=none`。旧联系人、关系、个人资料和头像上传写接口默认禁用；旧数据只读迁移、导入码、公开资料同步及本人头像迁移下载保留。

生产环境先准备 PostgreSQL 数据库及独立账号，并设置 `SPRING_DATASOURCE_URL`（`jdbc:postgresql://主机:5432/数据库名`）、`SPRING_DATASOURCE_USERNAME`、`SPRING_DATASOURCE_PASSWORD`、微信登录密钥、`AUTH_TOKEN_SECRET` 和 `APP_PUBLIC_BASE_URL`，再运行 `.\start.ps1 -Profile prod`。生产配置使用上述 Flyway 迁移和 Hibernate 结构校验，但**不会搬迁 H2 中的账号资料、固定导入码或公开资料**；已有用户切换数据库前应备份并安排数据迁移，不能直接指向空库上线。生产日志默认写入 `backend/logs/ai-network.log`，按 10MB 滚动并保留 30 份。`/actuator/health` 和 `/actuator/info` 可用于基础监控；未开放无认证的 metrics HTTP 端点。

## 微信登录与用户隔离

用户点击进入页按钮后才检查本机登录状态。登录时调用 `wx.login`，后端使用临时 `code` 换取 `openid`，再签发七天有效的访问令牌。本机数据以 `openid` 为键分别保存；联系人、统计、地图和人物关系在手机上管理。

首次使用本地版本时，小程序通过受认证的 `/api/local-export` 一次性读取该账号的旧资料、联系人和关系，全部成功写入本机后才切换到本地读写。导出或头像下载失败不会创建空数据，可重试。之后联系人和关系不会写回服务器；只有用户主动公开的资料会通过单独接口发布，用于导入码查询。旧服务器资料不会自动公开。首次迁移需要后端在线。

**本地存储注意事项：** 联系人和关系只在当前手机，不会自动同步到其他手机；卸载小程序、清理微信存储或更换手机可能导致新数据丢失。可在“设置 → 账号与安全 → 数据备份与恢复”生成加密文件，通过微信文件分享后另存到安全位置；备份密码需输入两次确认。每次保存资料都会记录修改时间，首页提示条、“我的”页和备份页据此提醒：从未备份、最近一次备份尚未分享保存、上次备份后资料有改动或超过 30 天未备份。只有已分享的备份才算完成；未分享的文件重新进入备份页后仍可再次分享。恢复前可预览联系人和关系数量，恢复会完整覆盖当前账号的本机数据；请先备份当前手机。备份密码至少 10 位，不会上传服务器；忘记密码无法恢复。备份包含本机头像。退出登录只清除登录状态，不清除本机资料。导入码需要网络与后端；仅公开昵称及选定字段会发布，关闭昵称公开会撤销可导入资料。头像仍保存在本机，不通过导入码分享。微信登录、旧数据首次迁移和 DeepSeek AI 提取也需要网络与后端。

“我的”及导入码页分别显示本机读取、网络错误和重试；导入码联网成功后按账号缓存，离线时显示缓存提示，不代表服务端状态已重新确认。公开资料显示待确认、失败、最近确认时间和重试入口；本机公开开关不等于服务器已生效。头像使用微信原生选择入口，压缩到最长边不超过 512 像素后先预览，确认才保存。本机缓存容量为小程序所有账号合计，头像文件大小单独展示，不构成完整文件系统用量统计。

设置功能补充：通用协议与 AI 授权按微信账号分别保存，旧版没有账号归属的授权不会沿用，已有用户会重新确认；授权弹窗期间切换账号不会把同意记到另一个账号。个人资料编辑显示未保存提示，并在微信支持时启用原生离页确认；恢复默认头像仅在明确选择并保存后清除旧照片，成功后尝试释放被替换的本机头像文件。

“退出此手机”保留本机资料，仅清理本机登录状态；“退出所有设备的在线登录”需要联网及新微信凭证复核，撤销服务器上的旧令牌，但不会删除或锁定其他设备的离线资料。“导入码与公开资料”支持联网读取服务器实际公开字段，以及重新验证身份后重置导入码；旧码立即失效，已有导入副本和公开字段不受影响，其他手机缓存的旧码需联网重新获取。预览、同步和重置之间阻止冲突操作。

“隐私与授权”撤回全部同意前，可先进入公开资料管理，也可保留公开内容继续撤回；撤回不自动撤下公开资料。授权记录清理失败会显示错误，不能显示撤回成功。设置首页概览来自本机最近的公开状态及备份记录；需要确认服务器当前内容时，请打开实际公开资料预览。“帮助与反馈”提供版本、常见问题、微信权限管理、主动复制脱敏诊断和微信原生意见反馈；不自动发送反馈或诊断，诊断不包含账号、密钥、联系人及后端地址。

备份页保留当前账号最近 5 次生成／分享的元数据记录；历史记录不等于保留 5 份文件。每个账号只保留最新加密临时源文件，再次生成会替换该文件；分享失败可在本页重试，无需重复加密。请通过微信另存备份；分享成功也不保证接收方已经长期保存。恢复预览会提前说明是否需要联网同步公开资料，明确失败尝试回滚，结果不确定时保留恢复数据并提示重试。

“设置 → 账号与安全 → 注销当前账号”经过两次确认（第二次输入“注销”）和新微信临时凭证复核。服务器先以事务删除当前账号资料、导入码、公开资料及旧联系人关系，撤销旧令牌，提交后尝试清理当前关联头像；收到明确成功响应后才清理当前手机该账号本机数据。请求前必须保存本机恢复记录；尚未发送注销请求的登录失败会解除该记录，已发送后结果不明则保留资料并要求继续确认。服务器注销事务同时保存回执摘要，响应丢失或本机确认写入失败时，可用新微信凭证查询回执再清理，不重复删除；回执按每次操作保留，后续注销不会覆盖旧设备的回执。恢复期间阻止普通重新登录、导入码获取和资料同步，以免旧流程重建账号。重进入口或“我的”会跳转继续处理。其他账号资料、其他手机数据、已经生成／分享的备份和他人已导入副本不会自动删除，历史孤立头像需运营方单独清理。服务器保留账号单向摘要与会话版本以阻止旧令牌复用，再次登录会建立新账号资料。

本轮修正了 `UserProfileStore` 的 Spring 构造器注入，运行时使用数据库存储而非测试内存实现；旧开发进程内未落库的临时资料／导入码不会自动迁移，重启后需重新获取确认。新增 `V3__add_account_sessions.sql` 持久化会话撤销状态，`V4__add_account_deletion_receipt.sql` 保存单向回执摘要，生产环境由 Flyway 执行，开发环境由现有建表配置更新。前后端代码必须一起更新，重启后端、运行 `npm run build` 并重新编译小程序后才生效。本轮未执行真实账号注销。

本机资料仍未加密存储，也未增加联系人云同步；加密仅用于导出备份。隐私说明中的运营主体和联系方式仍须团队提供真实信息后补齐。

新增联系人页支持粘贴文字后预览 AI 提取结果、保存时提醒可能重复的联系人，以及按“姓名 | 单位 | 职务 | 城市 | 电话”逐行批量录入。批量保存会先校验所有选中记录，再一次写入本机。不提供拍照或上传名片进行 OCR 识别。真机验证步骤及尚未完成的验证见 [真机测试清单](docs/真机测试清单.md)。

```powershell
$env:WECHAT_APP_ID = "你的小程序AppID"
$env:WECHAT_APP_SECRET = "你的小程序AppSecret"
$env:AUTH_TOKEN_SECRET = "至少32位的随机字符串"
```

启用 AI 联系人提取时，在后端运行环境配置 DeepSeek API Key。默认请求地址是 `https://api.deepseek.com/chat/completions`，默认模型是 `deepseek-flash`，因此通常只需设置密钥：

```powershell
$env:DEEPSEEK_API_KEY = "你的DeepSeek API Key"
```

国内省级地区和全部地级市的地图坐标随小程序打包在 `miniprogram/utils/region-points.ts`，进入省份和城市时直接本地定位，不需要网络、后端或 Key。同一文件还收录了美国各州、加拿大、澳大利亚、英国、日本、韩国的主要州省，以及常见国家的主要城市，可按中文或英文名称匹配（如“加州 / California”、“东京都 / Tokyo”）；国外国家本身的地图中心取自地球轮廓数据。离线表中没有的地点（其他国外地区、县级市等）才请求后端，由后端调用腾讯位置服务地理编码；查到的坐标缓存在本机（最多 300 个），再次进入无需联网。需要定位这类地点时，在后端运行环境配置腾讯位置服务 Key（在[腾讯位置服务](https://lbs.qq.com/)控制台申请）：

当前小程序通过 `POST /api/maps/locations` 提交本机已有的国家、省份、城市及待定位地区名称，每批最多 30 个；后端只返回坐标，不读取服务器旧联系人来生成人数或标记。地图人数、标记名称和联系人列表均以本机数据为准，超过 30 个地区时分批查询。旧 `GET /api/maps/locations` 为兼容早期客户端保留。定位服务不可用时，已设置准确坐标的联系人仍可显示；无法定位的地区会显示提示，联系人列表不受影响。前后端需要一起更新并重启后端。

```powershell
$env:TENCENT_MAP_KEY = "你的腾讯位置服务Key"
```

地球视图使用随小程序一起打包的离线边界数据，不依赖该 Key；未配置时国内地区仍可完整下钻和定位，只有离线表之外的地点会提示暂未定位。联系人已有的经纬度且不为空时优先使用；没有保存位置的联系人显示为城市附近的半透明估算标记，并在列表中提示设置位置。切换底部标签返回地图时，若本机联系人没有变化，则保留原来的下钻层级、搜索词和地图，不重新加载。城市中相互靠近的联系人标记会聚合为人数气泡，点击放大后展开（需微信基础库 2.21.0 及以上，旧版本逐个显示）。新加坡、马耳他等轮廓数据中没有的小国家，在地球上以固定中心点显示标记。地球的绘制、按需重绘、边界和触控逻辑在 `miniprogram/utils/globe.ts`，地图页只负责数据和跳转。地球外观选择性接入地图分支提交 `3e473db`：三张纹理随包离线加载，云层静态显示，保留静止不重绘和离页暂停；云层及水面纹理失败时保留基本地球，离页释放 GPU 资源并忽略迟到回调。未覆盖当前地图数据、搜索、入口视频和开发端口；本地仍默认 8080，定位接口已支持带查询参数。省级边界轮廓目前只有江苏（`assets/data/jiangsu.js`）。其他省份的轮廓需等确认合规的数据来源（国内发布的地图须使用经审核的边界数据）后再接入，暂不随意下载第三方边界数据。

后端沿用现有的 OpenAI 兼容请求和 JSON 解析逻辑，小程序仍调用 `POST /api/ai/extract`，无需改动页面。需要覆盖默认值时，可设置 `DEEPSEEK_BASE_URL`、`DEEPSEEK_MODEL` 和 `DEEPSEEK_TIMEOUT_SECONDS`；基础地址可填写服务根地址或以 `/v1` 结尾的地址，后端会补上 `/chat/completions`。旧的 `AI_API_KEY`、`AI_BASE_URL` 和 `AI_MODEL` 不再用于此接口，避免把其他服务商的密钥发送到 DeepSeek。未配置 `DEEPSEEK_API_KEY` 时，其他功能仍可使用，AI 提取接口会返回“AI 提取服务尚未配置”。真实密钥不得写入配置文件或提交到 Git。设置密钥后需重新启动后端；正式调用需要服务器能访问 DeepSeek API。

后端不会提供默认令牌密钥；缺少 `AUTH_TOKEN_SECRET` 时将拒绝启动。生产环境还应设置实际网页来源和公开地址：

```powershell
$env:CORS_ALLOWED_ORIGIN_PATTERNS = "https://你的管理后台域名"
$env:APP_PUBLIC_BASE_URL = "https://你的后端域名"
```

微信小程序原生请求不受浏览器 CORS 限制。演示联系人默认关闭；仅需要本地演示时设置 `$env:DEMO_DATA_ENABLED = "true"` 后启动服务。

同时将根目录 `project.config.json` 的 `appid` 替换为同一个小程序 AppID，在微信公众平台配置生产后端的 HTTPS 请求合法域名。未配置 `WECHAT_APP_ID` 和 `WECHAT_APP_SECRET` 时，登录接口会返回“微信登录尚未配置 AppID 和 Secret”，不会回退为共享演示用户。

## 隐私合规

- **协议与同意：** 登录页须勾选同意《用户协议》《隐私政策》后才能登录；同意记录按版本保存在本机。正文在 `miniprogram/utils/legal.js`，由 `pages/legal` 展示。正文有实质变化时修改 `miniprogram/utils/consent.ts` 中的 `LEGAL_VERSION`，所有用户下次从进入页进入时会被引导重新确认；确认后优先复用本机账号，已有资料可离线进入，仅缺少有效身份时才重新联网登录。
- **上线前必须完成：** 把 `utils/legal.js` 中所有【】占位内容（运营者名称、联系邮箱、服务器所在地、日志保留期限）替换为真实信息，并由运营方核对正文与实际数据处理一致。
- **AI 单独同意：** 首次使用智能整理前单独询问是否同意把粘贴的文字发送给 DeepSeek，同意后才发送；可在「设置 › 隐私与授权」撤回，撤回后再次使用会重新询问。
- **微信隐私授权：** 读取剪贴板、选择相册/拍照、选择聊天文件的页面都放置了 `<privacy-popup />`（`components/privacy-popup`），在微信要求授权时展示说明并通过 `open-type="agreePrivacyAuthorization"` 按钮完成授权。新增调用隐私接口的页面必须加入该组件，`tests/privacy-compliance.test.js` 会检查。
- **微信公众平台配置（需人工完成）：** 在「设置 › 服务内容声明 › 用户隐私保护指引」中如实声明：剪贴板（读取：粘贴人物介绍、批量录入；写入：复制导入码、选中的联系人电话或邮箱）、选中的照片或视频（更换头像，仅存本机）、摄像头（拍摄头像）、选中的文件（从聊天选择备份文件恢复）。如实填写开发者处理信息的目的，审核通过后接口才能正常使用。
- **撤回与删除：** 「设置 › 隐私与授权」可查看协议和微信隐私保护指引、撤回 AI 授权、撤回全部同意并退出登录。删除服务器上的账号记录、导入码和早期版本数据目前需用户联系运营方，由运营方处理。

## 打开小程序

1. 打开微信开发者工具。
2. 导入仓库根目录。根目录配置会自动将 `miniprogram` 识别为小程序源码目录。
3. 在开发者工具中勾选“不校验合法域名、web-view 域名、TLS 版本以及 HTTPS 证书”。
4. 确认后端已在本机 `8080` 端口运行，然后点击编译。

第一次运行地图前，在微信开发者工具中执行“工具 → 构建 npm”，将 `threejs-miniprogram` 编入小程序。地球先显示带加载提示的底色球体，再分批加入陆地纹理、国界和装饰；只在拖动、缩放、转动或数据变化时重绘，下钻到省市或离开页面时停止绘制；画布像素比最高为 2，国界按颜色合并为最多 4 次绘制。WebGL 地球和原生地图的触摸交互需要在开发者工具与真机分别确认。

小程序模拟器默认访问 `127.0.0.1:8080/api`。复制 `miniprogram/utils/api-config.local.example.js` 为同目录的 `api-config.local.js`，填写 `deviceDevelop`（电脑局域网地址）、`trial` 和 `release`（实际 HTTPS 后端地址）。这个文件不提交 Git，但需要随小程序构建一起上传。无需改动 TS 和生成 JS；真机未配置地址时会明确报错。真机须与电脑同网，并在微信公众平台配置体验版和正式版的请求合法域名。局域网 HTTP 只用于开发。

进入页和登录页的背景视频相互独立：进入页保持原有的视频和封面；登录页的视频由后端提供（`backend/src/main/resources/static/videos/background.mp4`），地址与 API 同一主机，加载失败时显示渐变背景，不影响登录。登录页不要写死 `127.0.0.1`。

## 主要接口

| 方法 | 地址 | 用途 |
| --- | --- | --- |
| POST | `/api/auth/wechat-login` | 微信登录 |
| GET | `/api/local-export` | 首次迁移时只读导出旧数据 |
| POST | `/api/ai/extract` | AI 联系人信息提取 |
| POST | `/api/maps/locations` | 按本机地区名称查询坐标，不上传联系人和人数 |

联系人、关系、看板、地图和标签使用小程序本地数据层，不再向这些旧服务端接口写入。

分类迁移和日常读取使用相同的旧编号修复规则。历史分类超过 16 层或 1000 个时仍可保留、导出和恢复；新增分类继续执行 16 层、1000 个的限制。备份恢复仍拒绝重复编号、无效引用及非法字段，导出不会改写原本机记录。

## 测试

后端测试使用独立的内存 H2，不会读取或修改本机正式数据：

```powershell
Set-Location backend
.\mvnw.cmd test
```

测试完成后，覆盖率报告位于 `backend/target/site/jacoco/index.html`。

首次安装依赖在项目根目录运行 `npm ci`，随后运行 `npm run build`、`npm run check`。已有依赖时直接构建和检查。`npm run check` 包含严格 TypeScript 类型检查和全部前端测试；`npm test` 单独执行前端测试。

有 `.ts` 的模块以 TypeScript 为维护源，修改后由 `npm run build` 生成对应 JavaScript，不要手工维护两份逻辑。图谱页面 `pages/graph/index.js`、绘图算法 `utils/graph.js`、分类逻辑 `utils/categories.js` 等只有 `.js` 的模块直接维护 JavaScript，构建不会覆盖这些文件。不要按旧压缩包说明删除已有 `.ts`。构建还会复制 Worker 所需的加密库，微信开发者工具编译前需完成构建；备份使用后台 Worker 执行密码派生，旧版本不支持时会提示更新，不降低加密强度。GitHub 的 PR 检查会执行严格类型检查、全部前端测试、后端验证、生成文件一致性检查及 jar 密钥检查。

只运行图谱相关测试时执行：

```powershell
node --test tests/graph.test.js tests/graph-tree.test.js tests/graph-categories.test.js tests/graph-page.test.js tests/contact-form.test.js
```

图谱测试使用虚构资料和内存存储，不依赖 `startDemo()` 或清空数据模块，不会读写手机上的联系人。它们覆盖绘图算法、布局、分类及推荐项、离线访问、备份兼容、刷新、搜索和新增入口；测试通过不代表画布渲染、手势或真机性能已验证。当前图谱真机项目仍标为待测。

同步外部测试时，仅合入适配当前行为的图谱场景。保留当前公开资料待确认状态、并发数据保护、原子分片和备份等回归测试，不用旧测试文件整体覆盖。

微信 `wx.login` 失败或未返回 code 时，登录页显示具体失败信息，并提示检查开发者工具微信登录状态、小程序 AppID，或用真机重试；后端接口失败继续按原错误流程提示。

关系新增／编辑表单绑定打开时的账号，账号切换后清空旧表单并拒绝保存；离页期间忽略迟到读取与保存完成回调，同账号返回后可恢复或重新读取。地图加载中改变或清空搜索词，以当前输入为准，旧加载不会恢复旧搜索，离页后的全局查询不再更新页面。
